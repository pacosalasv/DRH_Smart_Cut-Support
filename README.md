## Read this first

Planned, not built. No download, no date. The repository exists to collect whether this is a real gap or a tool I want for my own work.

## The idea

Hard-surface cutting tools that respect the surface they're cutting: panel lines, vents, and seams that follow curvature instead of a straight knife across a compound angle.

## What's decided and what isn't

Settled: hard-surface focus, and a cutting workflow rather than a boolean generator, because a boolean you can't clean up is a different problem.

Open: how much of this Blender's own knife projection already solves for the surfaces people actually model. Until I can answer that with real geometry, building it would be guessing.

## The honest alternative

If the problem is placing parts on a surface, [Object Layout Studio](https://github.com/pacosalasv/DRH_Object_Layout_Studio-Support) already aligns against evaluated bounds, which covers more of the "it won't sit flush" complaints than you'd expect.

[Open an issue](https://github.com/pacosalasv/DRH_Smart_Cut-Support/issues) with the shape you couldn't cut cleanly. That's the input worth having.
